# doc-intel

Production-oriented document intelligence pipeline built with:

- **Go** for orchestration and service APIs
- **Python** for model-facing extraction and evaluation workflows
- **VLMs** for multimodal document understanding
- **Redis** for queueing and async job coordination
- **PostgreSQL** for durable document/job/result storage
- **Evaluation** workflows for quality measurement and regression tracking
- **Async processing** for scalable ingestion and analysis
